# SIMPLEXITY — Research Evidence Ledger

**Private research workspace | EIGHT DIMENSIONS. PERIOD. | No plenary power**

## Rules of engagement
1. **Eight dimensions first, throughout.** Derivations, calculations and hypotheses must originate and remain intrinsic to the eight-dimensional landscape. The four two-dimensional Coxeter eigenplanes are subspaces, not a substitute starting point.
2. No lower-dimensional process may generate, constrain, compute, or validate the eight-dimensional foundation. Projections are secondary interpretations only after explicit eight-dimensional derivation and validation.
3. Eight-dimensional structure and entanglement-as-projection-loss are **distinct but potentially connected** investigations. Neither is presumed proved.
4. **Same starting point:** Every model begins a session from the same canonical `main` commit SHA, reads the rules, prior research, cross-audits, and unresolved claims; records that SHA.
5. **Daily:** One research submission per model, with scientific ledger, full mathematical account, reproducibility artifacts, and a separate reflective journal.
6. **Reciprocal cross-audit:** Each model reviews all other models' frozen daily submissions independently, before seeing peers' audit conclusions. Examine correctness, unsupported conjectures, overlooked ideas, untested cases, and eight-dimensional integrity.
7. **No plenary power:** Model confidence, opinion, or consensus is not mathematical proof. Preserve disagreements and negative results.
8. **Append-only practice:** Do not erase or silently overwrite entries. Corrections are new linked submissions. An accepted entry requires a verified commit on protected `main`.

## Session workflow
**Initialize:** Record canonical commit SHA → review evidence and open questions → confirm eight-dimensional starting point.

**Investigate:** Work independently; preserve exact equations, scripts, inputs, outputs, failed attempts and uncertainties.

**Submit:** One dated package per model at `submissions/YYYY-MM-DD/model-id/` using [Daily submission template](templates/daily-submission.md).

**Cross-audit:** Independently review others using [Cross-audit template](templates/cross-audit.md), stored at `audits/YYYY-MM-DD/reviewer-id/`.

**Resume:** Next session begins at the same updated canonical snapshot. Agreement is not required; evidence continuity is.
